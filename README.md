# Task Management App

A full-stack Task Management application built using React, Node.js, Express.js, and MongoDB.

## Features

- Create tasks
- View all tasks
- Update task status
- Mark tasks as completed or pending
- Delete tasks
- REST API integration
- MongoDB database
- Responsive user interface

## Technologies Used

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- REST API
